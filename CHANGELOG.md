# Changelog

## 0.1.0 - 2026-10-16

- First release of the MrScraper extension for Gemini CLI.
- Hosted MCP server `https://mcp.mrscraper.com/mcp` (Streamable HTTP, OAuth 2.1
  with dynamic client registration) exposing `scraperAPI`, `webSearch`, and
  `status`.
- Skills: `mrscraper`, `mrscraper-fetch`, and `mrscraper-serp`.
- Commands: `/mrscraper:fetch`, `/mrscraper:search`, and `/mrscraper:status`.
- `GEMINI.md` context with tool routing guidance.
